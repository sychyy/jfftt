# Perbaikan JFT Basic — 15 Oktober 2026

## Perubahan
- Renderer soal War memakai `JFTQuestionBank.renderQuestionMarkup`, sama seperti latihan biasa, sehingga label, visual/title, body bacaan/pesan, tabel, dan pertanyaan tampil bersama.
- Layout opsi War memakai pola dan breakpoint dua kolom yang sama dengan latihan biasa pada layar besar, satu kolom pada layar kecil.
- Pemilihan bank soal menghapus soal berulang berdasarkan kombinasi kategori dan teks pertanyaan yang dinormalisasi, selain memastikan ID unik.
- War Quiz memvalidasi `question_ids` dari room sebelum mulai. Jika daftar lama berisi soal berulang/ID tidak valid dan jumlahnya jadi tidak sesuai, pemain diarahkan kembali agar host memulai ronde baru; daftar soal tidak diam-diam diulang.
- Error TTS hanya dicatat di console; popup/alert error TTS di latihan, War, dan pemutaran ulang hasil dihilangkan.
- Animasi masuk halaman dan animasi pergantian soal ditambahkan dengan dukungan `prefers-reduced-motion`.

## Validasi lokal
- Seluruh file JavaScript lolos `node --check`.
- Seluruh 1.000 soal JSON berhasil diparse.
- ID unik, teks pertanyaan unik per kategori, indeks jawaban valid, dan opsi dalam setiap soal tidak duplikat.
- Semua referensi file lokal yang ditemukan di atribut `src`/`href` HTML mengarah ke file yang tersedia.

Catatan: validasi lokal tidak menggantikan uji multiplayer realtime pada Supabase produksi. Tidak ada perubahan skema, SQL, RLS/policy, konfigurasi, atau data Supabase.
