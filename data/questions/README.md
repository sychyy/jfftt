# Bank soal JFT Basic

Bank soal ini telah diganti dari empat PDF sumber yang disediakan. `vocab.json` berisi soal 1–20 per PDF; `grammar.json` berisi soal 21–30 serta Conversation and Expression; `listening.json` berisi soal choukai. Setiap soal menyimpan sumber, nomor soal, kunci jawaban dari halaman KEY ANSWER, dan gambar potongan halaman sumber.

PDF tidak menyertakan file audio choukai. Field `audioSrc` disiapkan untuk file yang akan diunggah nanti di `assets/audio/choukai/basicN-qN.mp3`; file audio belum ada di paket ini. PDF juga tidak memiliki bagian Reading Comprehension yang terpisah, sehingga `reading.json` dikosongkan agar soal lama yang tidak berasal dari sumber baru tidak tercampur.
